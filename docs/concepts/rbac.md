# RBAC (Role-Based Access Control)

Kullanıcılara rol atayarak (Yönetici/Editör/İzleyici gibi) sistem içi yetkilerini kısıtlayan erişim kontrol modeli. [[entities/eticaret-stok-uyari-sistemi]]'nde takım bazlı, [[entities/eticaret-gorsel-uretimi]]'nde `USER`/`ADMIN` ikili biçiminde, [[entities/cv-hazirlama-otomasyonu]]'nda B2C/B2B ayrımı biçiminde görülüyor.
